# Resume Builder

A full-stack MERN application that allows users to create, edit, and manage professional resumes easily. Users can input their personal details, education, experience, and skills to generate a structured resume with a live preview.

## Features
* Create and edit resumes
* Structured resume generation
* Resume preview with thumbnail
* Responsive user interface
* Multiple resume templates
* PDF export

## Tech Stack
* **Frontend:** React.js, Axios
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Other:** REST APIs, Git
